An object identifying the style of conversation—'Debate', 'Discussion', or 'Interview'—providing context for interaction dynamics and analysis.

## Overview

ConversationStyle Object identifies the style of the conversation or debate, such as "Debate", "Discussion", or "Interview". This classification provides context for the interaction dynamics and helps tailor the analysis to the specific format, affecting scoring and interpretation.

## Applications

### 1) Coder's Perspective

Coders include the conversation style in the `Turn` Object to adjust analysis parameters and scoring algorithms based on the interaction format.

### 2) User's Perspective

Users can see the conversation style to better understand the context of the speaker's remarks and the expectations for their performance.
